◎Overview

Connecting intent with interaction

GUI grounding maps an operation intent to a specific interaction target and the spatial parameters needed to act.

Graphical user interface agents automate tasks by interpreting user goals and executing interface operations. Grounding is the critical link between high-level reasoning and low-level interaction execution.

This survey organizes grounding methods along three complementary dimensions, reviews training datasets and evaluation benchmarks, and compares representative methods across target types, instruction complexity, and interaction requirements.

The roadmap below traces the development from visual grounding and interface modeling to screenshot-based localization, visual search, and iterative refinement.

3Inference strategies

Organizing evidence for localization

Inference strategies differ in whether they predict directly, introduce auxiliary evidence, compare hypotheses, or refine a target using intermediate predictions.

1Direct

Predict the target from the current interface and instruction without constructing auxiliary evidence or refining an intermediate target.

2Guided

Use candidate elements, spatial references, or semantic reformulation to support target selection.

3Multi-hypothesis

Aggregate or assess predictions from repeated sampling, different views, or reasoning branches.

4Iterative

Use an intermediate target hypothesis to update the evidence for subsequent localization.

4Target representations

From model output to an actionable location

Target representations specify what the model predicts; spatial readout turns that prediction into the geometry required for execution.

Coordinates

Explicit numerical geometry: click points, bounding boxes, drag endpoints, or trajectories. Predictions must map correctly to the screen’s coordinate frame.

Spatial responses

Target-related scores over visual patches, pixels, or regions. A spatial readout derives the final location from these scores.

Elements

Select a target from native or visually reconstructed interface elements, then retrieve its associated geometry.

5Datasets & evaluation

Measuring grounding across interfaces

Data resources and benchmarks reveal how grounding transfers across platforms, target types, instruction complexity, and interaction requirements.

Training resources

Interface coverage and instruction–target supervision provide the foundation for learning. Data differs in platform, annotation source, and the types of interaction it supports.

Localization accuracy

Point-based metrics test whether a prediction falls inside the target. Region-based metrics can measure overlap between predicted and reference geometry.

Benchmark diversity

ScreenSpot evaluates grounding across desktop, mobile, and web interfaces; ScreenSpot-Pro tests high-resolution professional environments and small targets.

Beyond static clicks

Spatial and functional references, absent targets, dragging, and state-dependent interactions test capabilities beyond matching visible text to a single point.
