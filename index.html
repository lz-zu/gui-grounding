01Overview

Connecting intent with interaction

Computer-use agents interpret user goals and act through graphical interfaces. GUI grounding connects high-level reasoning to low-level execution: it maps an operation intent to a specific interaction target and the spatial parameters needed to act.

This survey brings together the methods, training resources, and evaluation protocols behind that capability. We organize methods along three complementary dimensions—learning paradigms, inference strategies, and target representations—and examine how their strengths vary with target types, instruction complexity, and interaction requirements.

The field has developed from visual grounding and interface modeling toward screenshot-based localization, visual search, and iterative refinement. The roadmap below situates these developments.

02Method taxonomy

Three dimensions, one grounding problem

How is the capability acquired? How is evidence used at inference time? How is the target expressed? These dimensions describe complementary aspects of a method, rather than mutually exclusive families.

Learning paradigms describe where grounding ability comes from: broad multimodal pretraining, GUI-specific adaptation, or training-free use of existing models.

04Inference strategies

From one prediction to progressive refinement

The same model can ground a target in different ways. Inference strategies determine how it uses hints, considers alternatives, and revisits uncertain regions.

01

Direct

Predict the target from the instruction and interface in one grounding step.

02

Guided

Use explicit cues or intermediate reasoning to focus the prediction.

03

Multi-hypothesis

Generate and compare multiple candidate targets or predictions.

04

Iterative

Revisit the interface through successive localization and refinement steps.

05Target representations

What does the model point to?

An interaction target can be encoded as a position, a spatial response, or an interface element. The representation affects how predictions are interpreted and turned into actions.

x,y

Coordinates

Points and regions express where to act directly in the interface coordinate system.

▦

Spatial responses

Spatial scores or response maps preserve evidence about where a target may lie before a final location is selected.

</>

Elements

Identifiers or structured element descriptions connect a prediction to an interface object.

06Datasets & evaluation

Measuring grounding in context

Training data provides interface coverage and instruction–target supervision. Evaluation asks whether that capability transfers across platforms, dense layouts, ambiguous instructions, and richer interaction requirements.

Target localization

Point accuracy tests whether a predicted location falls inside the target region; region-based evaluation can measure overlap.

Interface diversity

Benchmarks such as ScreenSpot and ScreenSpot-Pro examine different platforms, resolutions, and target sizes.

Instruction understanding

Spatial and functional references test whether a model resolves the intended target beyond matching visible text.

Interaction requirements

Absent targets, dragging, and state-dependent interactions extend evaluation beyond a single static click.
