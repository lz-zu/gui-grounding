# GUI Grounding Survey — project website

Project page for **GUI Grounding for Computer-Use Agents: A Survey**.

- Website: https://lz-zu.github.io/gui-grounding/
- Paper: https://doi.org/10.20944/preprints202611.0431.v1
- Research collection: https://github.com/OmniAI-Lab-CUHKSZ/Awesome-GUI-Grounding

## Local preview

Run `python3 -m http.server 8765` in this directory, then open http://localhost:8765/.

The site uses static HTML, CSS, and JavaScript without a build step. GitHub Pages publishes the root of the `main` branch. Update `index.html` for research content, `styles.css` for layout, and `site.js` for interactions. The paper reader uses `assets/paper.pdf`. Keep the citation in `index.html` and `citation.bib` synchronized.

Figures and manuscript originate from the survey; cite the authors when reusing research content.
